📊 Core Analysis Agents

📈
Technical Analysis Agent
agents/technical_analysis_agent.py

Computes 6 technical indicators and generates composite BUY/SELL/HOLD signals. Each indicator votes +1 (bullish), -1 (bearish), or 0 (neutral). The composite score determines the final signal.

RSI (14) MACD Bollinger Bands EMA Crossover Stochastic ADX
💬
Sentiment Analysis Agent
agents/sentiment_analysis_agent.py

Fetches recent news headlines from Alpaca's news API and analyzes sentiment using VADER. Scores range from -1 (bearish) to +1 (bullish). Helps confirm or contradict technical signals.

News API VADER Sentiment Headline Analysis
🔄
Mean Reversion Agent
agents/mean_reversion_agent.py

Detects oversold/overbought conditions where price deviates significantly from its mean. Best suited for ranging/sideways markets. Uses statistical Z-score to measure deviation.

Bollinger Bands RSI Extreme Z-Score Stochastic
⏱️
Multi-Timeframe Agent
agents/multi_timeframe_agent.py

Analyzes price action across multiple timeframes to confirm signals. A signal is stronger when multiple timeframes agree. Prevents false signals from short-term noise.

1 Minute 5 Minutes 1 Hour 1 Day
🔍
Scanner Agent
agents/scanner_agent.py

Autonomous agent that continuously scans multiple stock universes for trading opportunities. Runs TA on each symbol in parallel, detects market regime, and can automatically execute trades through the trading pipeline.

Parallel Scanning 6 Universes Auto-Execute Loop Mode

⚠️
Risk Management Agent
agents/risk_management_agent.py

Enforces strict risk controls before any trade executes. Checks position concentration limits, portfolio exposure, and buying power. Rejects trades that exceed risk parameters.

Position Limits Exposure Caps Buying Power

Portfolio Manager Agent
agents/portfolio_manager_agent.py

Coordinates all analysis agents and makes final trade decisions. Weighs signals from different sources and determines optimal position sizing based on portfolio state.

Signal Coordination Decision Making Position Management
🚀
Execution Agent
agents/execution_agent.py

Places orders via Alpaca API with retry logic for reliability. Handles order submission, fill verification, and error recovery. Supports market and bracket orders.

Order Placement Retry Logic Fill Verification

Signal Aggregator
utils/signal_aggregator.py

Combines signals from TA, Sentiment, and MTF agents with configurable weights. Produces a unified score and confidence level for trade decisions.

Weighted Scoring Confidence Calc

Position Sizer
utils/position_sizer.py

Uses Kelly Criterion to calculate optimal position size based on win rate, payoff ratio, and volatility. Prevents over-betting while maximizing growth.

Kelly Criterion Risk-Adjusted

Market Regime Detector
utils/market_regime.py

Classifies current market conditions into regimes: TRENDING_UP, TRENDING_DOWN, RANGING, VOLATILE, or BREAKOUT. Adjusts strategy weights based on regime.

Trend Detection Volatility Analysis
🔀
Correlation Filter
utils/correlation_filter.py

Prevents buying stocks that are too correlated with existing positions. Ensures portfolio diversification and reduces concentrated risk.

Correlation Check Diversification

Trailing Stop Manager

Monitors open positions and adjusts stop-loss levels as price moves favorably. Locks in profits while allowing winners to run.

Dynamic Stops Profit Protection

Orchestration End-to-End

🤖 Autonomous Trading Mode

The Scanner Agent enables fully autonomous trading with scan_and_run()

📡 Continuous Mode

Scans the market every N seconds and automatically executes trades on the best opportunities.

pipeline.run_continuous("VOLATILE", interval=60)

🎯 Single Scan

Scan once, find opportunities, and execute trades in one call.

scan, results = pipeline.scan_and_run("MOST_ACTIVE")

🔍 6 Universes

VOLATILE, MOST_ACTIVE, TECH, SP500_TOP50, CRYPTO_RELATED, DEFAULT — or provide custom symbols.

⚡ Parallel Scanning

Scans multiple stocks in parallel using configurable worker threads for fast execution.
